# 📚 ScoutNote

ScoutNote is a free educational website created to help students access organized notes for Classes 10, 11, and 12.

## 🌟 Features

- 📖 Class 10 Notes
- 📘 Class 11 Notes
- 📙 Class 12 Notes
- 💼 Commerce Stream
- 🔬 Science Stream
- 🎨 Arts Stream
- 📱 Mobile-Friendly Design
- ⚡ Fast and Lightweight

## 🎯 Mission

Our mission is to make quality study notes available to every student for free, helping them prepare for exams more effectively.

## 🛠️ Built With

- HTML5
- CSS3
- GitHub Pages
